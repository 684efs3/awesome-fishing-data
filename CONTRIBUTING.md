# Contributing to Awesome Fishing Data

Thanks for helping grow this list! It's maintained by
[FishRadar](https://fishradar.ai) and the curation is released under CC0.

## Guidelines

Please make sure any resource you add is:

1. **Open or freely usable** — open data, an open/free API, or open-source
   tooling. Paywalled or proprietary-only resources don't belong here.
2. **Relevant** — about fishing, fish species/taxonomy, marine biodiversity,
   ocean/weather conditions, bathymetry/marine GIS, or fisheries.
3. **Accurately described** — one concise sentence explaining what it actually
   provides. No marketing fluff.
4. **Still alive** — the link works and the project isn't abandoned.

## How to add an entry

1. Fork the repo and create a branch.
2. Add your entry to the most fitting section in `README.md`, keeping entries
   roughly alphabetical within the section. Format:

   ```markdown
   - [Name](https://example.com) — One-sentence description of what it provides.
   ```

3. If you're adding a whole new category, add it to the **Contents** list too.
4. Open a pull request describing the resource and why it's useful.

## Quality bar

This is a curated list, not a link dump. PRs that add low-quality, redundant,
or off-topic links may be declined. When in doubt, open an issue first to
discuss.
